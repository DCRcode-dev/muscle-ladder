- **Logged history:** the app links sets to a *position* within each day (`day_index`), not to the exercise name. Because exercises were re-ordered/added/removed, any sets you logged before today may no longer line up — re-log going forward (the data they were attached to was incorrect anyway).
- **Files changed:** `index.html` (live data + muscle map), `programs.js` (kept in sync). Cache bumped `v4→v5`, build `ota-4` — the fix installs on next app launch.
- **Backups:** originals saved in the outputs folder before any edit.
